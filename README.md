# Expense-Tracker_project

A simple command line interface project built with python. This app help the uses to track their expenses

## 🚀 Features

- 1. Add expense
- 2. View expenses
- 3. Search expenses
- 4. Show total spending
- 5. Show spending by category
- 6. Delete expense
- 7. Export expenses
- 8. with json datafile 

## 🛠️ Technologies
- **Languages** - Python, JSON
- **Tools** - Git
