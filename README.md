💰 Expense Tracker

A simple command-line expense tracker built with Python that helps users manage and monitor their daily expenses. It allows users to add, view, search, categorize, and delete expenses while keeping track of their total spending.

🚀 Features

- ➕ Add Expense — Record expenses with details such as amount, category, date, and description.
- 📋 View Expenses — Display all recorded expenses.
- 🔍 Search Expenses — Find specific expenses quickly.
- 💵 Show Total Spending — Calculate the total amount spent.
- 📊 Spending by Category — View expenses grouped by category.
- 🗑️ Delete Expense — Remove an expense from the records.
- 📤 Export Expenses — Export expense records for external use.

🛠️ Technologies

- Language: Python
- Tools: Git, GitHub

⚙️ Installation and Setup

1. Clone the Repository

2. Navigate to the Project Directory

cd Expense-Tracker_project

3. Run the Application

run:

python main.py

Depending on your system, you may need to use:

python3 main.py
